# Vue Hybrid App 🚀

A modern, lightweight hybrid Vue.js application built with the latest technologies for optimal performance and user experience.

## ✨ Features

- **⚡ Lightning Fast**: Built with Vite for instant hot reload and optimized builds
- **📱 Mobile Ready**: Fully responsive design that works on all devices
- **🔧 Modern Stack**: Vue 3 + Composition API + Pinia + Vue Router
- **🚀 PWA Support**: Progressive Web App with offline capabilities
- **🎨 Modern UI**: Clean, modern design with smooth animations
- **🌙 Theme Support**: Built-in light/dark theme switching
- **📦 Lightweight**: Minimal bundle size with code splitting

## 🛠️ Technology Stack

- **Vue 3** - Progressive JavaScript framework
- **Vite** - Next generation frontend build tool
- **Vue Router** - Official router for Vue.js
- **Pinia** - Intuitive state management
- **PWA** - Progressive Web App capabilities
- **Modern CSS** - Grid, Flexbox, and CSS custom properties

## 🚀 Quick Start

### Prerequisites

- Node.js 16+ 
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd vue-hybrid-app
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```

5. **Preview production build**
   ```bash
   npm run preview
   ```

## 📁 Project Structure

